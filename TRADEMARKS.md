# Trademark policy: Galaxy Download Manager

The code of Galaxy Download Manager is open source under RPL-1.5 (see [`LICENSE`](LICENSE) and [`NOTICE.md`](NOTICE.md)). The **names and logo are not**. This policy explains how they may be used. It follows the model of Firefox and Rust: the code is free to study, use and change, while the name tells users which builds come from the original project.

The marks: "Galaxy Download Manager", "GDM" (for download software), "Golden IQ", and the Galaxy Download Manager logo. They are claimed by Golden IQ and Chhit Sungchhay (the Licensor). RPL-1.5 Section 5.0 grants no right to them.

## Allowed without asking

- Using and redistributing **unmodified official builds** (from the project's GitHub Releases or winget) under the original name, for example on a mirror or in a software catalogue.
- Saying truthfully that something works with, or is based on, Galaxy Download Manager, for example "based on Galaxy Download Manager" or "a fork of GDM".
- Naming the project in articles, reviews, tutorials and teaching material.
- The attribution that RPL-1.5 itself requires (Sections 6.2 and 6.4(d)).

## Not allowed without written permission

- Publishing a modified version, or a build made from modified source, under the name "Galaxy Download Manager" or "GDM", or under a name or logo that could be confused with them. RPL-1.5 Section 6.0 already requires a modified version that is Deployed to have a distinct title.
- Using the logo, or a logo that looks like it, for any modified version, website, store listing or product.
- Presenting a build, website, extension or store listing as official, endorsed or made by the Licensor when it is not.
- Using the marks in a domain name, account name or app ID in a way that suggests it is official.

## Asking for permission

Open an issue in the project's GitHub repository with the title "Trademark request" and describe the intended use. Permission is given only in writing, by the Licensor.
